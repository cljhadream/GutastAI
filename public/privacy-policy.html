八、IP 风险检测工具

“Claude IP 风险检测”页面在您的浏览器中运行，用于核对您访问 Claude 时的网络出口，其数据处理方式如下：

  • 浏览器直接访问的第三方：为获取出口信息，您的浏览器会直接向 claude.ai、api.anthropic.com、1.1.1.1（Cloudflare）、my.ip.cn / 2026.ip138.com、status.claude.com 以及 Google / Cloudflare 的 STUN 服务器发起请求。这些请求由您的浏览器直接发出，不经过本站服务器；
  • 发送到本站的内容：仅 Claude 出口 IP 一个字段会被发送到本站接口，用于查询 IP 情报。时区、浏览器语言、操作系统等环境信息只在您的浏览器本地读取用于比对，不会发送到任何服务器；
  • 第三方查询与缓存：本站接口将收到的出口 IP 转发给 ipapi.is 查询机房 / VPN / 代理 / Tor 等标记，并转发给 RIPEstat（RIPE NCC 提供的公开数据服务）查询该 IP 的注册国家，查询结果在 Cloudflare 边缘缓存 24 小时以减少重复查询，到期自动失效；除此之外本站不保存 IP 或查询结果；
  • 本地历史：检测历史（Claude 出口 IP、所在国家与检测时间）仅保存在您浏览器的 localStorage 中，点击页面“清除”或清除浏览器数据即可删除，不会上传到本站。
