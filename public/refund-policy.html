一、总则

本政策适用于通过 Gutast AI（gutast.com）下单的全部服务，包括 ChatGPT Plus / Codex 官方渠道代充与 Claude Code 代充套餐。本政策与服务协议共同构成您与我们之间的完整约定。

二、可全额退款的情形

  • 办理开始前：付款后服务尚未开始办理的，支持全额退款；
  • 开通失败：官方渠道未划扣成功、未能按约定开通对应服务的，全额退款；
  • 我方原因：因我方原因未能按承诺内容交付的，全额退款。

三、开通成功后的说明

订阅类虚拟商品一经官方开通即完成交付，按行业惯例不支持无理由退款。开通成功后，您将收到 OpenAI / Anthropic 官方账单收据（Paid Receipt）作为交付凭证，对应权益在整个订阅有效期内有效。

四、全周期订阅质保

在会员整个有效订阅期内，我们提供官方异常兜底与质保服务：

  • 订阅期内出现官方权益异常的，我们提供恢复指导与协助处理；
  • 无法恢复的，视情况提供补偿或按剩余订阅时长折算的解决方案；
  • 具体质保方案以办理时顾问书面确认为准，到期前 3 天顾问会主动提醒，续费与否由您自主选择。
