## 1. 核心战略与信任心智（Trust Framework）
真实数据背书：页面顶部突出 正规会员代充 ｜ 累计服务顾客 1,665 位。
核心四大承诺：
自有账号办理：直接为用户的现有账号开通，无需更换新账号，保留历史 Prompt 与上下文。
无需提供密码：办理过程中不需要向客服提供账号密码，彻底消除隐私外泄与 Token 风险。
支持正常续费：官方正规渠道，到期后原账号仍可继续续费或再次办理，不伤号、不降权。
全周期订阅保障：在会员整个有效订阅期内提供官方异常兜底与质保服务。
直面价格异议（杀手级卡片）：
设立专门板块解答 “为什么我们的价格比别人高？”：拆解官网 $20 美元采购硬成本，曝光低价黑卡被撤销、封号的内幕，把“价格高”转化为“100% 正规、不坑号”的核心卖点。

## 3. 光影与深度规范 (Elevation & Glow)

为了塑造“悬浮在能量场上”的立体感，定义以下阶梯式光晕系统：

* **`shadow-glow-orange`（主 CTA / 推荐卡片）**：
  ```css
  box-shadow: 0 0 35px -5px rgba(255, 94, 30, 0.45);
  ```
* **`shadow-glow-orange-lg`（弹窗 / 强交互）**：
  ```css
  box-shadow: 0 0 50px -5px rgba(255, 94, 30, 0.65);
  ```
* **`shadow-glow-card`（Claude Code 展台）**：
  ```css
  box-shadow: 0 0 30px -10px rgba(99, 102, 241, 0.25);
  ```
* **顶部宇宙光晕（Hero Radial Aura）**：
  在首屏后方居中放置 `700px * 350px` 的椭圆径向光晕：
  ```css
  background: radial-gradient(circle, rgba(255,94,30,0.2) 0%, rgba(99,102,241,0.15) 50%, transparent 100%);
  filter: blur(120px);
  ```
