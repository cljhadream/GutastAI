## 系列 A：原理干货（复制第 01 篇验证过的模板）

问题驱动标题 + 结论前置 + 原理拆解 + 可照抄命令/清单。公共知识为主，人人可搜，但学爸视角的讲法是差异化。

### A1. 机房 IP 和家里宽带的 IP，Claude 是怎么一眼认出来的？
- **核心干货**：ASN（自治域）是什么；数据中心 IP 段 vs 住宅 ISP 段；IP 信誉库怎么积累"前科"；为什么"我换了 IP 还是秒封"。
- **大纲**：① 结论前置：风控不查"你是谁"，查"你的 IP 属于谁" ② ASN 是什么，一段比喻讲清（小区门牌 vs 写字楼门牌） ③ 三层判定：ASN 归属 → 信誉库前科 → 行为特征 ④ 自查：`curl ipinfo.io` 看哪个字段 ⑤ 哪些情况住宅 IP 也会出事（动态拨号池、共享出口）
- **学爸切入点**：我以为翻墙换个 IP 就没事了，结果孩子问我"爸爸你的 IP 住在哪个小区"，我才去搞懂 ASN。
- **内链机会**：gutast IP 检测工具（2-3 处）

### A2. AI 编程助手聊久了会"失忆"？上下文窗口到底是怎么回事
- **核心干货**：上下文窗口 = 模型的工作记忆；token 数怎么涨；超了以后发生什么（截断/压缩）；CLAUDE.md 和 /compact 为什么是"外挂记忆"。
- **大纲**：① 结论前置：AI 不是忘了，是你的话"出了它的桌子" ② 工作记忆比喻：桌面大小固定 ③ 一个长会话的 token 账单演示 ④ 三个实操：任务拆小、CLAUDE.md 写规矩、阶段性 /compact ⑤ 失忆的连带风险：改到一半忘了之前的约定
- **学爸切入点**：让孩子背课文背到第 30 分钟就开始忘第一段，AI 也一样。

### A3. Token 到底怎么计费？我的 Claude Code 一晚烧了多少钱
- **核心干货**：token 是什么（中英文字符的粗算）；输入输出价差（5 倍左右）；缓存命中为什么能省钱；订阅制 vs API 按量的账模型。
- **大纲**：① 结论前置：AI 编程的成本不在对话次数，在"每次带了多大一摞上下文" ② token 粗算表 ③ 输入输出价差与缓存 ④ 一晚真实会话的账单拆解（估算演示） ⑤ 什么时候订阅划算、什么时候按量划算（给边界）
- **学爸切入点**：第一次看账单以为是扣错了，拆完才知道是"每次都把整本书递给 AI 看"。
- **内链机会**：gutast Claude Code 充值指南（2-3 处）

### A4. 什么是 Agent？它和你一句我一句的聊天机器人差在哪
- **核心干货**：Agent = 模型 + 工具调用 + 循环；为什么 Claude Code 能自己读写文件、跑命令；权限确认为什么不能全跳过；失败兜底（它卡住了怎么办）。
- **大纲**：① 结论前置：聊天机器人给答案，Agent 干活 ② 一次工具调用的完整回路演示 ③ 循环与终止条件 ④ 权限确认是安全带，不是麻烦 ⑤ Agent 卡死/跑偏的三个信号
- **学爸切入点**：孩子问"它怎么知道去读哪个文件"，正好用"老师布置任务 vs 递答案"来比喻。

### A5. AI 为什么一本正经地胡说八道？幻觉的来源和两条防线
- **核心干货**：幻觉的三个来源（训练数据、采样随机性、无实时知识）；为什么越流畅越危险；两条防线：要求给来源、外挂知识库（RAG 的家长版解释）。
- **大纲**：① 结论前置：幻觉不是 bug，是"接话茬"机制的副产品 ② 三个来源各配一个生活比喻 ③ 亲历案例：孩子让 AI 编 API 用法，编得像模像样 ④ 防线一：让它说依据 ⑤ 防线二：RAG = 开卷考试
- **内链机会**：可链第 01 篇

## 系列 B：实操干货（频道差异化，别人写不了）

### B1. Claude Code 开工第一天：我的十分钟开工清单（命令可照抄）
- **核心干货**：装完之后要做的 5 件事；CLAUDE.md 初始化模板；第一个任务怎么下才能跑通；环境自查命令汇总（承接第 01 篇）。
- **大纲**：① 清单总览 ② 逐条展开，每条配可照抄命令 ③ CLAUDE.md 最小可用模板 ④ 第一个任务的"下指令三要素" ⑤ 常见第一次翻车点
- **内链机会**：充值指南 + IP 检测（3-4 处）；与第 01 篇互链

### B2. Prompt 怎么写 AI 才不跑偏？我踩坑后总结的 4 个写法
- **核心干货**：给结构（markdown 框架）；给上下文（贴报错全文而不是转述）；给边界（不许动哪些文件）；让 AI 先复述任务再动手。
- **大纲**：① 结论前置：AI 跑偏 90% 是指令的锅 ② 四个写法逐一配前后对比示例 ③ 一个真实翻车→修复案例 ④ 让孩子当裁判：哪版指令更清楚
- **学爸切入点**：辅导孩子写作文和给 AI 下指令是同一门手艺。

### B3. 家长陪孩子用 AI 学编程，分工怎么定？我的"AI 干活、我来把关"五条规则
- **核心干货**：方法论长文：AI 做什么（初稿、解释、重复劳动）/ 人把关什么（需求、验收、安全）；孩子的提问训练；屏幕时间的边界。
- **大纲**：① 五条规则总表 ② 每条配真实场景 ③ 孩子从"让 AI 写作业"到"指挥 AI 做项目"的转变 ④ 一个亲子小项目复盘 ⑤ 什么必须人工（账号、支付、隐私）
- **内链机会**：文末 1-2 处

### B4. 网络明明正常，为什么 Claude 老断线？IP 稳定性自查实战
- **核心干货**：IP 跳变（重拨换 IP、代理池轮换）对风控的影响；"IP 频繁变"和"IP 固定但可疑"哪个更糟；自查步骤：定点观测 IP 一天、看变化频率和 ASN 一致性。
- **大纲**：① 结论前置：风控怕的不是你的 IP 差，是它一直在变 ② 什么动作会引发 IP 跳变 ③ 一天的观测实验（命令 + 记录表） ④ 判读：多久变一次算异常 ⑤ 稳下来的三条路（给边界）
- **内链机会**：gutast IP 检测（3 处）；与第 01 篇互链

### B5. Claude Code / ChatGPT / Cursor，怎么选？一家人用完一个月的实话
- **核心干货**：三者定位差异（终端 Agent / 通用对话 / IDE 内嵌）；给边界：谁适合谁不适合；家庭场景组合建议；成本对比。
- **大纲**：① 结论前置：没有全能选手，只有场景匹配 ② 三者各自一次真实任务的表现 ③ 选型边界表 ④ 我们家的最终组合 ⑤ 新手最省钱的起步路径
- **内链机会**：充值指南（2 处）
