### 硬门槛：官网只收海外卡

Claude 官网只支持海外信用卡和 PayPal，不支持支付宝与微信——这是所有充值路径讨论的起点。2026 年国内用户可行的路，按安全性从高到低排序如下。

### 五条路径安全性排序

1. **海外真实信用卡**：最稳，门槛最高
2. **PayPal**：仍然需要海外卡，没有额外优势
3. **美区 App Store / Google Play 礼品卡**：正规，但流程折腾
4. **虚拟卡 VCC**：不推荐新手——拒付风险、卡商跑路、还可能连累账号风控
5. **代充服务**：支付宝/微信直付，关键看模式

### 代充的两种模式：一字之差，天壤之别

- **密码托管模式 = 高危**：把账号密码交给对方，账号失控、个人资料泄露，随时人财两空
- **官方会话代付模式 = 安全**：你在**自己账号**的官方升级页发起订阅，对方只负责付款，全程不需要密码，账号始终在你手里

**防坑第一原则：任何索要账号密码或验证码的代充，直接拉黑。**

### 正规代付的三步流程

以 Gutast AI（www.gutast.com）为例：自有账号确认档位 → 支付宝/微信人民币付款给专席 → 在官方会话内发起升级、专席代付。支持开发票，运营主体与 D-U-N-S 编码公开可查。

同一条路径也支持 **ChatGPT Plus / Codex**（¥145/月起）与 **Claude Code 代充**（¥11 起七档算力套餐）。
