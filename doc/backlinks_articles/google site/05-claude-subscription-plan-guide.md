### 2026 年 10 月新福利：订阅送 API 额度

订阅与 API 首次打通——Max 5x 每月送 **$100** API 额度、Max 20x 送 **$200**、Team 最高 $500。领取方式：设置 → 账单 → 绑定 Console 组织，免绑卡，新订阅满 7 天可领。这让 Max 与 Pro 的实际差价比表面更小。

### 选档逻辑

- 用得少：API 按量付费可能最便宜
- 天天用：Pro 起步
- 天天开 Claude Code 且经常顶到上限：Max 5x（算上每月 $100 API 额度福利，实际差价更小）

### 省钱四原则

1. **先按月别年付**：政策变化快，降低敞口
2. **把税和换汇成本算进总价**：标价 ≠ 实付
3. **新号从 Pro 起步**：直接冲 Max 容易触发 KYC 审核
4. **远离拼车共享号**：转售共享已被官方单独写成红线
