## 踩过的坑（沿用 xbplan-illustrator 验证过的经验）

1. 旁白"我"是爸爸，别画妈妈；
2. 图里的字全是乱码——屏幕只写"散发柔和的蓝光/抽象色块"，不描述具体界面内容；要真实界面就后期叠截图；
3. 不写人数会多出路人，脚本默认已带"只有这N个人"；
4. 留白被画满就换一张，比改词快；
5. 同构图变体：把第一张成图当 `ref`，只改要变的部分（白天↔夜晚、平静↔兴奋）；
6. 竖版 size 未验证，稳妥先出 16:9 再裁。
