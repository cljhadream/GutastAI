## 先给结论：成本大头不是"你说了多少句"，是"每轮递给 AI 多大一摞上下文"

> **核心结论**：AI 编程按 token 计费。最反直觉的地方在于：你每说一句话，模型都要把之前的全部对话重新读一遍。会话越聊越长，每一轮都更贵——账单失控几乎都是这么来的，跟单价关系反而不大。

## Token 是什么：AI 的"字数计价单位"

模型不按"一句""一条"收费，按 token 收。token 可以理解成模型用的"字块"，咱们不需要深究原理，记住粗算规则就够用：

- 1 个英文单词约等于 1.3 个 token；
- 1 个汉字约等于 1~2 个 token；
- 一页 A4 的普通文章，大约 800~1200 个 token。

为什么聊得越久越贵？关键机制在这：**每一轮对话，模型都要"从头读一遍之前的全部对话"**。你发的是一句话，它读的是一整本越来越厚的书。

拿我自己的会话举例（每轮新增约 1000 token，数字取整便于理解）：

1. 第 1 轮：模型读约 1000 token；
2. 第 3 轮：读约 3000 token；
3. 第 10 轮：读约 10000 token；
4. 第 30 轮：读约 30000 token——同样一句"继续"，成本是最初的 30 倍。

再叠加两个价差，账单结构就完整了：

- **输出比输入贵好几倍**：让模型"生成"比让它"阅读"贵，所以让它大段复述、大段输出没改动的代码，都是在花冤枉钱；
- **有缓存折扣机制**：重复出现的前缀（比如每次都一样的系统提示、CLAUDE.md）可以打折计费。这也是为什么[上篇的开工清单](../claude-code-first-day-checklist/README.md)里让你把规矩写进 CLAUDE.md——重复交代十次，不如写在固定位置让缓存吃掉。

## 我的省钱四招（照抄版）

1. **任务拆小，一个任务一个会话**：账单失控的头号原因就是把一整天的活儿堆在同一个会话里，让"那本书"越滚越厚。做完一件事，开新会话，历史包袱清零；
2. **规矩写进 CLAUDE.md**：项目背景、你的水平、红线要求，写在固定文件里让缓存去消化，别每轮都用对话重复交代；
3. **先方案、后动手**：让它先列计划、你确认了再写代码。返工一次，等于把全部历史重读一遍，还多付一次"生成"的溢价；
4. **轻量学习用订阅，重度批量才研究按量**：给边界——像我这种每周做几个小项目的学习型用户，订阅比盯着按量账单省心；如果你要跑大批量自动化任务，再去细算按量计费的账。

第三招配套的提示词，我每天都在用：

```text
Keep your answers short: explain in a few sentences, and only show
the code you actually changed. Do not repeat files you did not modify.
```

> **新手心得**：省钱的核心不是抠搜着用，而是别让"上下文这本书"无序变厚。会话管理做得好，成本自然是一条平线；做得差，它就是一条指数曲线。

## 我的复盘：同样的活儿，两种花法

第一周我的用法是典型反面教材：一个会话从早聊到晚、让它反复大段重写、随时插进新点子。第二周改成分会话 + 先方案后动手之后，做同样多的事，花销明显下来了——具体数字跟每个人的用法强相关，我就不晒账单制造焦虑了，但**成本结构**是每个人一样的：会话长度 × 轮数 × 单价。前两个变量都攥在你自己手里。

想自己核对的，Claude Code 里可以直接查本会话的用量统计，开工清单里养成"收工看一眼"的习惯，一周后你对"多少钱一晚上"就有体感了。
