## 注册前先想明白的三件事

动手之前，先把这三个认知摆正，能省掉后面一半的麻烦：

1. **地区是硬前提**：Claude 官方有支持地区列表，要求使用人实际位于支持地区。换网络出口只是配合手段，不改变这个前提——这也是为什么所有"教程"都从网络讲起，而不是从官网讲起；
2. **账号归属自己**：邮箱、密码、验证方式都要握在自己手里，长期可控。凡是"代注册、代保管"的，账号本质上就不是你的；
3. **注册不难，稳定才难**：大部分翻车不是发生在注册那一晚，而是之后的使用里。所以准备工作做在前面，比事后补救省心。

> **风险提示**：先把丑话说在前面——没有任何配置能保证"绝对不封号"。这篇教你的是把该做的准备做对、少走弯路。想深入了解风险逻辑的，可以看我之前整理的[环境自查](../claude-code-starter-notes-01/README.md)和这篇[封号风险分析](https://www.gutast.com/blog/claude-ban-risk-guide.html)。

## 第一步：把网络出口稳住——先懂"住宅 IP"，再谈配置

注册时，Claude 看到的"你"就是你的 IP。这也是[第 03 篇讲过的知识点](../datacenter-ip-vs-home-ip/README.md)：机场的机房 IP 出身是数据中心（ASN 归属是云厂商），在注册这种敏感环节天然可疑；而家庭宽带的住宅 IP，出身就是普通美国家庭，可信度高得多。

所以第一步不是买，而是**分清两类产品**：

- **机房代理 / 动态轮换代理**：便宜，但 IP 来自数据中心且经常变，注册场景别用；
- **静态住宅 IP**（Static Residential）：一条固定的美国住宅出口，IP 长期不变，这才是我们要的。价格大致每月几美元，以服务商官网实时价格为准。

新手照抄版清单：

1. 选一家提供"静态住宅 IP"的服务商，认准 Static Residential，别买成机房或轮换类型；
2. 套餐从最小配置起步：1 个 IP、地区指定美国、流量选低档就够个人学习用，别被"默认 1000 个 IP"的大单吓住，数量手动改成 1 再结账；
3. 有"高信誉 IP / IP 信誉筛查"这类加购选项的，预算允许可以加上，作用是挑选历史口碑更好的 IP——它是筛 IP 的，不是"防封险"，别理解错；
4. 买完拿到代理信息（服务器地址、端口、用户名、密码），导入代理客户端（Windows 上常用 Clash Verge 这类），把"日常节点 → 美国住宅 IP"接成链式代理，让 claude.ai 的流量走住宅出口；
5. 配置完**别急着注册**，先做出口检测，确认你的出口确实是美国住宅 IP，再进入第二步。

第 5 步我用的检测工具是 [Gutast AI 的免费 IP 风控检测](https://www.gutast.com/claude-ip)，网页上输入 IP 就出报告，不用注册，报告里会告诉你这个 IP 的归属类型和风险评分。服务商我自己用的是 Webshare，注册走的是[我的邀请链接](https://www.webshare.io/?referral_code=r382aur0jyca)——对你没有任何加价，我拿一点返佣，就当请我喝杯咖啡。至于前面几步具体在哪个页面点哪个按钮——怎么选套餐、去哪抄代理信息、Clash 里链式代理怎么绑，我写了一篇[美国住宅 IP 配置全流程](https://www.gutast.com/blog/claude-home-ip-setup-guide.html)，照着一步步点就行。

> **新手心得**：网上流传"把浏览器语言改成英文、系统时区改成美国"的偏方。这类设置没有官方依据说是必需，属于锦上添花；真正要紧的是别让系统时间乱跳、别一边美国 IP 一边时区对不上。我之前写过一篇[时区风控自查](https://www.gutast.com/blog/claude-code-timezone-risk-check.html)，纠结这个的可以先看它。

## 第二步：把手机号准备好——+86 收不到验证码的两条路

注册 Claude 时要填手机号收验证码，目前中国大陆的 +86 号码收不到（以注册页面实时提示为准）。所以第二步要提前把号码准备好，两条路线：

**路线 A：海外虚拟号接码（按次付费）——适合"先注册体验"**

在接码平台按次买一个海外号码，验证码直接显示在网页上，一次几毛到一美元不等，收不到码一般自动退回余额。用法上记住三件事（下单步骤、哪一步最容易卡，我展开写过一篇[手机号验证全解](https://www.gutast.com/blog/claude-phone-verification-guide.html)，照着做就行）：

1. 下单时选对目标网站（选错了收不到码）；
2. 选号码国家时，优先看成功率，再看价格，国家尽量和你 IP 的地区一致（第一步用的是美国 IP，就选美国号）；
3. **风险必须说透**：这类号码是临时租的，用完过期会回收给下一个人。以后账号再要短信验证，你就收不到了。所以它只适合"注册了先体验"的场景，不适合放重要账号。

**路线 B：属于你自己的海外真号——适合"长期当主力"**

比如英国 giffgaff 这类可以长期持有的 eSIM 号码，成本高一点，但号码一直是你的：换设备重新验证、二次验证、找回账号，都稳。

我的建议很简单：先想清楚 Claude 对你是"试用玩具"还是"主力工具"。试用，走路线 A，几美元搞定；当主力（比如像我这样每周都要用它学编程），号码这步一步到位，别省。

## 第三步：正式注册——照着清单走一遍

网络和号码都备齐了，正式进门：

1. 浏览器确认走的是住宅出口（第一步的检测报告是绿的再来）；
2. 打开 claude.ai，选 Continue with Google 或邮箱注册。推荐用长期在用的邮箱，别用临时邮箱；
3. 邮箱注册会收到登录链接或验证码，注意在发起注册的同一台设备、同一个浏览器上完成，别跨设备倒腾；
4. 到手机验证这一步，填第二步准备好的号码，等验证码到达后填入；
5. 注册成功先别关页面：进设置确认账号邮箱是不是你自己、界面归属对不对——这一步很重要，后面订阅充值才不会充错账号；
6. 免费额度内先试用，确认符合需求后，再在 Settings → Billing 里按需升级套餐。

注册过程中还可能遇到另外几种验证，遇到了别慌，按页面提示走就行：

- **KYC 身份验证**：要求上传证件加实时自拍，用原件、光线清楚，信息真实有效；
- **年龄验证**：官方走 Yoti 流程，按邮件指引完成，年满 18 岁是硬要求；
- **支付方式验证**：绑定支付方式时可能触发，用真实有效的支付信息，别用来路不明的卡。

> **新手心得**：注册环节翻车的，十有八九出在网络上（出口 IP 跳变、IP 类型不对、时区打架），而不是"操作点错了"。所以第一步宁可多花十分钟做检测，也别检测没过就硬着头皮注册。卡在半路反复失败的，先把完整流程对着[这篇注册指导](https://www.gutast.com/blog/claude-registration-guide.html)过一遍再重试，比盲目重试强。

## 注册完的三件收尾事

1. **把恢复方式存好**：注册邮箱的密码、备用验证方式，写进你的密码管理器。丢号比封号更常见；
2. **把使用习惯养好**：固定在同一个网络环境里登录，别今天住宅 IP、明天机场节点地切换，环境稳定比什么"养号秘籍"都实在；
3. **想长期用，提前研究套餐**：Pro 和 Max 怎么选、月付年付差多少，我整理在[这篇套餐对比](https://www.gutast.com/blog/claude-subscription-plan-guide.html)里，看完再掏钱。
